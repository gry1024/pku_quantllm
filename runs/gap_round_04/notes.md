## 设计（事前登记，2026-09-18）

1. **diff4 消融链补全**：三件套 g4_01（链上唯一缺口：裸 0.276 → ×换手 0.292 → ?）
2. **振幅窗平台扫描**：amp 3/5/7/10（g4_02/01/07/03）——若 3–10 全平台则参数稳健
3. **amp 单独贡献**：diff4×amp 无换手版（g4_04），隔离哪个乘法器有效
4. **组合对照补全**：diff4×换手+PV（g4_05）、−日内4 三件套+PV（g4_06）
5. **最后两个未测核心假设**（日内回补跳空/gap fade）：
   −日内×gap 符号交互（g4_08）、−日内×|gap| 幅度交互（g4_09）
6. PV_ANTI_BARE 复跑（g4_10）：跨轮一致性锚点

## 读数

1. **振幅窗死平台**（amp 3/5/7/10 → valid 0.279–0.288），且 amp 乘法器不带来增益
   （三件套 ≤ ×换手版）——跳空族的有效乘法器只有**换手**一个，与共振族
   "换手>量"第四次确认一致。消融链定稿：裸 0.276 → ×换手 0.292 → 三件套 0.280，
   增益在第二级耗尽。
2. **组合最终判定**：两个组合 +0.013~0.014，均低于 0.02 噪声线 → 按简形式纪律
   **不采纳组合**，正式定位：跳空分解族 ≈ PV_ANTI 族的新采样 + 机制细化。
3. g4_08 是全项目第一个"动量语义"读数为正的结构（取负号后 gap×intraday 交互为正：
   跳空当日不回补 → 延续），但 |valid| 0.119 < 0.19 噪声门槛，不构成留存依据，
   记录为机制注脚：**延续成分存在于"跳空+日内同向确认"的交互里，强度不足以独立成因子**。
4. 早停判定：r3→r4 最优 valid 0.299→0.307（+2.7% <5%），连续两轮 <5% → **停止**。
   预算使用：56/80 次。
