# 跳空方向挖掘协议（事前声明，2026-09-18）

方向：**开盘跳空（隔夜信息/情绪机制）族的动量假设**。

- 主假设：跳空（尤其配合量能/活跃度结构）在 T+3 视界存在**延续**结构；
- 镜像假设（先验更强）：三项目综合结论"A 股 T+3 唯一方向是反向"——跳空是隔夜情绪过热的
  暴露，大幅高开 = 关注度冲击 → 后续**反转**；
- 证伪友好：若两种读法都不成立，以负结果收场，如实报告（沿 mom_protocol 条款）。

机制登记（跳空 = 隔夜信息 + 散户隔夜情绪；A股隔夜溢价长期为负）：
1. 裸跳空动量/反转（当日、5/20 日累计隔夜收益）
2. 隔夜-日内分解与不对称（高开低走型、方向计数、惊讶度跳空）
3. 无方向幅度类（隔夜波动、绝对跳空——彩票型/信息不确定性，预期负）
4. 跳空×量能/活跃度（相关型、量能加权方向、换手乘法器、三件套移植）
5. 趋势门控跳空（线上跳空，对照 m1_14 教训）
6. 日内结构对照（日内收益动量、尾盘强度）

## 验证设计变更（落实 [[wiki/concepts/factor-overfitting]] 2026-09-18 审计）

旧 valid 2015–2016 已被前三族消耗 ~1130 次，本轮**弃用**；分段整体后移：

| 段 | 区间 | 说明 |
|---|---|---|
| train | 2008-01-01 ~ 2016-12-31 | 含旧 valid；对跳空族为全新训练段 |
| valid | 2017-01-01 ~ 2018-12-31 | **新段**；曾作为旧三族 test 被观察（3 次终局 + 1 次跨方向排序），属间接加热，绝对值解读打折，但从未有任何跳空族候选在其上被选择 |
| test | 2019-01-01 ~ 2020-08-31 | **挖掘期间隐藏**（config `eval_test=false`），仅终局观察一次 |
| lockbox | 2020-09-01 ~ 数据末尾（约 2024） | 终局分年表会展示；**留存决策在运行 final_report.py 前冻结**，事后不因 test/lockbox 表现回改 |

台账按新 valid 段从 0 重新计数；本轮预算 ≤80 次。

## 预算与停机（沿用户标准）

- 轮次：≤4 轮；每轮 10–20 候选；总预算 ≤80
- 早停：连续 2 轮最优 valid |RankIR| 提升 <5% 且无新结构方向；或方向证伪成立
- 噪声锚点（按预算上限 N=80）：√(2·ln 80) ≈ 2.96；valid ~487 天、重叠 label
  （T+1→T+3）有效样本 ≈ 487/2 ≈ 244，对应 |RankIR| 绝对优势门槛 ≈ 2.96/√244 ≈ **0.19**

## 选择纪律（沿 factor-overfitting 清单，含本轮新增三条）

1. 决策只看 train（信号存在性）+ valid（排序选择）；test/lockbox 不作选择依据
2. 统计不可区分（valid |RankIR| 差 <0.02）取最简形式
3. 参数看平台不看峰值；组合只用正交成分等权，不调权重
4. 留存 ≤3 个因子；三票制（绝对优势 |valid RankIR|>0.19 + 经济机制 + 最简形式）至少两票；
   符号在留存时依 train+valid 一致方向确定
5. （新增）留存因子须记录与既有主推 PV_ANTI_TRIPLE 的 train/valid 段日均截面相关，
   作为正交性/合并判断素材（同源信号必须声明）
6. （新增）成本门槛：终局报告多头组日均换手 >60% 的因子，须三档成本（单边
   0.05/0.10/0.15%）下多空排序不变才可作主推，否则降级为观察项
7. 跨轮复跑一致性：至少 1 轮重跑，metrics 逐位对比
8. 涨跌停可交易性局限在报告中声明（跳空族天然暴露于一字板无法成交；反转语义下
   想买的低开票恰可能卖不出）
