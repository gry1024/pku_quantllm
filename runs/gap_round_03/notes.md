## 设计（事前登记，2026-09-18）

1. **diff 窗口细扫**：2/4 日裸 diff（g3_02/01，与 r1/r2 的 3/5/10/20 拼成完整窗口曲线）
   + diff3/diff4×换手（g3_03/04）+ diff3 三件套（g3_05）
2. **日内反转消融链**：−日内4 裸（g3_06）/×换手（g3_07）/三件套（g3_08），
   外加 −日内3 三件套（g3_09）
3. **与在位者的等权 rank 组合**（协议允许形式：正交成分等权，不调权）：
   diff3+PV（g3_10）、diff3 三件套+PV（g3_11）——回答"分解族是增量信息还是
   PV_ANTI 的又一次采样"
4. 支线复核：缩量跳空延续 gap3×(1−换手rank)（g3_12）、隔夜占比 3 日（g3_13，
   g2_08 的短窗复检）、diff3×趋势门（g3_14，对照 REV 族门控）

## 预期

- diff 3–5 平台、2/10 衰减；×换手版本 +0.02~0.05
- 组合若只与 max(成分) 打平（差 <0.02）→ 两族高度重叠，分解族定位"机制细化"
- g3_13 若 train 仍无信号 → 隔夜占比正式弃用
- g3_14 若 ≤ 裸 diff3 → 复现"趋势门控对非回调族有害"

## 读数

1. **diff 窗口平台成立**：2/3/4/5/10/20 → 0.180/0.261/0.276/0.238/0.163/0.186，
   3–5 日平台（4 日最优），与三项目"4–5 日窗"通识一致；×换手整体抬升一个台阶
   （+0.016~0.021）。
2. **组合无增量**：两个等权组合 valid 0.288/0.299 vs PV 单独 0.293——差值在噪声内。
   按 IC 流相关性近似（组合 IR/成分 IR ≈ √(2/(1+ρ))）反推 ρ_IC ≈ 0.75：
   **分解族与 PV_ANTI 族约四分之三的信息重叠**，剩余正交部分有限。正式数字见
   orthogonality.py 的截面相关输出。
3. 三条支线全部证伪（缩量跳空、隔夜占比、趋势门控），与"共振族无门控"结论一致。
4. 早停观察：r2→r3 最优 valid 0.293→0.299（+2.1% <5%），若 r4 仍 <5% 则停。
