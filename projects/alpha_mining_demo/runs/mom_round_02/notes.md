1. **52 周新高锚**（George–Hwang 锚定动量，唯一未测的经典动量族）：
   纯 close/ts_max(close,250)（m2_01）+ 量能确认版（m2_02）

5. **超短共振**：3 日同向天数（m2_06）、3 日收益-量变化相关（m2_07 是 3 日动量×换手；
   m2_08 是 corr(ret,dvol,3)——量价共振项目只测过 w=5，3 日是否翻号）

## B 线：新共振族取负诊断（m2_09–14）

round_01 全族为负 → 对 UVOL/MFI/同向天数/水平相关/高量上涨天数取负，问题变为：
**这些"共.convert量形态的反向版"是否优于/正交于裸反转 −Δ4**（0.398/0.300）？
若只是 −Δ4 的噪声重包装则全部出局；若含有独立信息（如量能维度的反向）则是本轮真正的产出。

判定：B 线因子 valid < 0.30（不及裸反转）且与反转族高度同源 → 出局；
≥0.30 且窗口/形式与裸反转有实质差异 → 进入正交性核查（后续轮）。

## 读数与转向

1. **动量证伪完成**：两轮 24/24 动量结构为负。结论：沪深300 成分股 T+3 视界上不存在可挖的
   量价共振动量；A 股"动量"只以"趋势内回调"形态存在（反转项目已挖到）。
2. **共振的反向语义跨形式稳健**：计数型（同向天数）、相关型（corr(ret,dvol)）、水平型
   （corr(close,volume)）、分解型（UVOL/MFI）取负后全部为正——量价共振 = 情绪过热 = 反向。
3. 计数型 m2_11 的 test 0.329 引人注目（对比：裸 −Δ4 test 0.163、REV_TRIPLE 0.205、
   VP_ANTI_RES5 test 0.280）——**计数型共振可能是比相关型更稳的载体**。
4. round_03 转向：对共振反向族系统挖掘（窗口曲线、量能加权、活跃度乘法器、
   计数×相关等权组合），复现 VP 项目 w=5 相关基线作会话内对照。
