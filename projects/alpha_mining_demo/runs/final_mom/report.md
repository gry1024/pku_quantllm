# 动量（价格×成交量共振）方向 · 自动化因子挖掘报告

- 挖掘方向：动量，核心思路为**价格与成交量的共振**
- 执行：ZCode 会话驱动，**6 轮 × 12–16 候选 = 84 个候选**，协议早停（连续两轮增益 <5%）
- 数据：沪深300 成分股日线 859 只（2008–2023），vnpy.alpha 表达式引擎
- label：`ts_delay(close, -3) / ts_delay(close, -1) - 1`（T+1 → T+3 收益）
- 分段：train 2008–2014 / valid 2015–2016 / test 2017–2020
- 协议：`runs/mom_protocol.md`（事前声明，含"证伪友好"条款）

## 核心结论一：动量被证伪

前两轮 24 个候选覆盖了动量的全部合理结构——裸动量（5/20/60 日）、52 周新高锚
（George–Hwang）、放量确认、缩量动量、涨跌日量能分解（UVOL/MFI/OBV）、水平共振
（corr(close,volume)）、量价同向计数、突破×量能、趋势内追涨、vwap 趋势、量冲击、
超短（3 日）共振——**valid 全部为负（−0.011 ~ −0.372）**。

结合反转项目的镜像读数（−Δ4 = +0.398 ⇒ +Δ4 = −0.398），结论确立：
**沪深300 成分股 T+3 视界上不存在可挖的量价共振动量；A 股的"动量"只以
"趋势内回调"形态存在**（即反转项目的 REV_TRIPLE）。

## 核心结论二：量价共振的实证语义是反向的——且被活跃度放大

对共振族取负后（round_02 B 线起），信号全面转正，最终结构：

```
PV_ANTI_TRIPLE = −corr(日收益, 日量变化, 5) × 截面换手排名 × 5日振幅
                 └── 共振强度（反向） ──┘  └── 谁被充分交易 ──┘ └ 分歧度 ┘
```

经济含义：高换手、高振幅、量价同动 = 分歧中的情绪过热（拉高出货/恐慌抛售），
未来 3 日回落。**活跃度乘法器是跨方向通用结构**（反转项目发现，此处移植并再验证），
它把 VP 项目主推 VP_ANTI_RES5（0.353/0.401/0.280）提升到 0.408/0.519/0.344。

## 最终因子（详见 factors.json 与 performance_report.md）

| 因子 | 表达式 | train | valid | test | test 多空 Sharpe |
|---|---|---|---|---|---|
| **PV_ANTI_TRIPLE（主推）** | −corr5 × cs_rank(turnover) × amp5 | 0.408 | 0.519 | **0.344** | **2.53** |
| PV_ANTI_PAIR（单乘法器对照） | −corr5 × cs_rank(turnover) | 0.387 | 0.519 | 0.318 | 1.87 |
| PV_ANTI_BARE（裸共振对照） | −corr5（=VP_ANTI_RES5） | 0.353 | 0.401 | 0.280 | 1.81 |

消融链 valid 0.401 → 0.519 → 0.519、test 0.280 → 0.318 → 0.344：换手乘法器贡献主要增量
（+30% valid / +14% test），振幅贡献小的正增量（test +8%，train +5%）。
主推取 amp5 而非 valid 最高的 amp10（0.530）：差异 2.1% 在选择噪声内，取短窗（简形式纪律）。

全样本十分组单调性 +1.00（完美单调）。

## 过拟合核查（按 [[wiki/concepts/factor-overfitting]] 框架自检）

1. **试验台账**：本会话 84 次尝试；同段 valid 累计消耗 ~940（VP）+ 106（REV）+ 84 = **~1130 次**。
2. **噪声锚点**：本会话 84 次的噪声最优 |t| ≈ √(2·ln84) ≈ 3.2；主推 valid RankIR 0.519
   → naive t ≈ 11.5（重叠 label 折半 ≈ 8.1），远超噪声上限；且增量（乘法器 +0.118 valid，
   diff-t ≈ 2）需要谨慎，但 test 段独立兑现（+8~14%）支持其真实性。
3. **参数平台**：corr 窗 3/4/5/6/7/10 = 0.458/0.513/0.519/0.504/0.500/0.499；
   amp 窗 5/7/10/15/20 = 0.519/0.525/0.530/0.527/0.528（死平台）；
   换手形式 4 种、振幅定义 2 种、价格锚 2 种均在 ±3% 内。
4. **复跑确定性**：跨轮 verbatim 复跑 5 次 + VP 项目主推跨会话第三次复现，全部逐位一致。
5. **结构性发现的可信度**：门控在共振族三次独立确认有害（0.453 vs 0.519）——
   与反转族相反的结构性差异本身就是信号真实性的旁证（数据没有"迎合"搜索方向）。

## 有效与无效的挖掘经验

有效：活跃度乘法器（cs_rank(turnover) 主力、amp5 次之）跨方向通用；
相关型 > 计数型 > 分解型（UVOL/MFI）> 水平相关型；换手 > 量（第四次确认）。
无效：一切动量结构（含 52 周新高、缩量、量冲击）；趋势门控（对共振族有害）；
激增比率换手形式；计数+相关等权组合；vwap 锚（略逊 close）。

## 三方向综合（本仓库因子知识现状）

1. A 股短线（T+3）唯一方向是**反向**：反转、反共振同源，都是"买分歧中的超跌"。
2. 两个跨方向通用结构：**活跃度乘法器**（换手×振幅，两方向都 +30% 级别增益）、
   **4–5 日窗口**（与 T+3 label 匹配）。
3. 一个方向特异结构：**趋势内门控**只对反转有效（反转要"线上回调"，反共振要"全场过热"）。

## 局限性

- 换手成本：多头组日均换手 54.8%，年化拖累 ~27%，扣费后多空年化约 +32%（全样本口径）；
  与反转因子同样需做换手-衰减权衡。
- 未做行业/市值中性化与可交易性校验（停牌/涨跌停），成分池非 point-in-time。
- test 段 Pearson IC（0.176 IR）弱于 RankIC（0.344 RankIR）——因子值的极端尾部含噪，
  实盘建议用分组/rank 口径执行。
- 2021 年 RankIC 最低（+0.020），低波动年份共振信号变弱；依赖高波动 regime。
