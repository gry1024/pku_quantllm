# gap_round_01 设计 — 跳空族谱扫描（16 候选）

## 假设地图（事前登记，评估前写于 2026-09-18）

跳空 = 隔夜信息 + 隔夜情绪的暴露。close_t/close_{t-1} = (1+gap_t)(1+intraday_t)，
故跳空族与既有价格动量部分重叠——本轮的增量问题是：**隔夜成分是否携带不同于
close-close 动量的信息，方向如何，何种结构下最强**。

1. **裸跳空基线**（动量/反转定标）：当日 gap（g1_01）、5 日累计隔夜（g1_02）、
   20 日累计隔夜（g1_03）、5 日累计日内（g1_04，隔夜/日内分解的另一半）
2. **隔夜-日内不对称**：隔夜−日内差（g1_05，"高开低走型"特征）、
   跳空方向计数 10d（g1_06，计数型，先验偏弱）、
   惊讶度跳空（g1_07，除以近期振幅，跨票可比）
3. **无方向幅度类**（彩票型/信息不确定性，预期负）：隔夜波动 20d（g1_08）、
   平均绝对跳空 10d（g1_09）
4. **跳空×量能/活跃度**：跳空-量变相关 10d（g1_10，相关型先验最强）、
   量能加权方向占比 5d（g1_11，OBV 式）、换手加权方向占比 5d（g1_12，MFI 式）、
   跳空×换手乘法器（g1_13）、三件套移植 −gap5×turnover×amp（g1_14 原号呈现）
5. **趋势门控**：线上跳空（g1_15，对照 m1_14"线上追涨最负"的教训）
6. **日内结构对照**：尾盘强度 5d（g1_16，收盘在日内区间位置）

## 预期（证伪友好）

- 若镜像假设成立：g1_02/03/13/14 为负（取负号后即反向因子），且 g1_13/14 强于裸 g1_02
  （活跃度乘法器移植成功）
- g1_04 若为正 → "隔夜反转、日内动量"的 A 股分解结构存在
- g1_08/09（无方向幅度）为负 → 彩票型解读
- g1_15 若为负 → 跳空族复现"线上追涨不行"；若转正 → 跳空延续需要趋势环境
- g1_10 相关型若同号强于 g1_11/12 计数/加权型 → 复现"相关型>计数型"排序

## 读数

1. **本轮真发现是隔夜-日内分解，不是裸跳空**：g1_05（隔夜−日内差）train +0.346 /
   valid +0.238，全表唯一双段强一致；机制上 = 「日内成分强反转（g1_04 −0.36）」
   +「隔夜成分不反转、甚至延续（g1_02 valid +0.20）」的叠加。与三项目综合
   "A 股 T+3 反向"一致，但把反转定位到了**日内部分**——隔夜部分豁免。
2. **裸跳空动量 train 无信号**（g1_01/02/03 ≈ 0）：valid 的 +0.18~0.20 按
   "train 信号存在性"纪律降权（train~0 + valid 正 = 典型选择诱饵形态）。
3. **活跃度乘法器对跳空族不增益**（g1_13/14 < g1_02）：乘法器结构边界确认——
   它放大的是过热型信号（corr/Δ），对本身无信号的 gap 动量无从放大。
4. 幅度类（g1_08/09）双段负：隔夜波动 = 彩票型/信息不确定性，预期兑现。
5. g1_11/12 train/valid 反号、g1_06/07/15 train 无信号 → 全部不进入后续轮。
