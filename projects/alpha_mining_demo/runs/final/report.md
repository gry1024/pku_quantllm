# 跳空方向因子挖掘报告（gap，2026-09-18）

协议：`runs/gap_protocol.md`（事前声明）。4 轮 × 56 候选（预算 80），早停与预算上限同时到达。
本轮是**过拟合防治纪律的首次全套升级实测**：新 valid 段、挖掘期隐藏 test、lockbox 冻结、
成本三档门槛全部落地。

## 验证设计（与前三族的关键差异）

| 段 | 区间 | 角色 |
|---|---|---|
| train | 2008–2016 | 信号存在性（含旧 valid，对跳空族全新） |
| valid | 2017–2018 | 排序选择（新段，从 0 计台账；曾作为旧三族 test 被间接加热，绝对值打折解读） |
| test | 2019–2020.08 | 挖掘期间隐藏（eval_test=false），终局观察一次 |
| lockbox | 2020.09–2024 | 留存冻结（retention.md）后仅由分年表观察 |

旧 valid 2015–2016 已被前三族消耗 ~1130 次，本轮弃用——落实 factor-overfitting 审计建议。

## 核心发现

1. **裸跳空动量证伪**：当日/5 日/20 日累计隔夜收益在 train（2008–2016）无信号；
   valid 的正读数（+0.18~0.20）属"train 无信号型"选择诱饵，按纪律降权。用户提出的
   "跳空动量"假设在裸形式上不成立。
2. **真发现：隔夜-日内分解**（全项目第 4 个有效结构）。`GAP_DIFF4 = Σ₄(隔夜收益 − 日内收益)`：
   日内成分是强反转（−日内5：train −0.36），隔夜成分不反转（隔夜累计 train ≈ 0）——
   **全日短线反转的信息几乎全部活在日内部分，隔夜部分豁免**。买"高开低走型"、卖"低开高走型"，
   train +0.379 / valid +0.276 / test +0.198。
3. **乘法器结构边界**：换手乘法器有效（diff4 0.276 → ×换手 0.292），振幅乘法器无效
   （三件套 0.280，amp 窗 3–10 死平台 0.279–0.288）——与共振族"换手>量"第四次一致，
   且证明振幅增益不跨族迁移。
4. **与在位族的关系：新采样而非替代**。GAP_DIFF4_TURN 与 PV_ANTI_BARE/TRIPLE、REV_TRIPLE 的
   日均截面 Spearman 仅 +0.32~+0.46（train/valid，orthogonality.py）；但两个等权组合对 PV 单独
   的 valid 增量 +0.013~0.014 < 0.02 噪声线 → 组合不采纳。解读：截面水平约 80% 方差正交，
   但正交残差太弱，可交易信息集中在两族共同活跃的交易日上。
5. **唯一正动量读数**（机制注脚）：g4_08 = −日内×跳空符号交互，train −0.152 / valid −0.119
   ——"跳空当日不回补（高开继续涨/低开继续跌）"有弱延续语义，是全项目第一个动量方向读数，
   但低于 0.19 噪声门槛，不构成留存。
6. 全部证伪支线：缩量跳空延续、隔夜收益占比（train 反号）、趋势门控（有害，复现共振族结论）、
   vwap 族（三次实验皆弱）、1 日窗（valid 死亡）、隔夜波动/绝对跳空（双段负 = 彩票型，方向兑现）。

## 终局确认（一次性观察，不回改留存决策）

- **test（2019–2020.08）**：三因子 RankIR 0.191–0.200，存活但相对 valid 衰减 ~30%；
  多空 Sharpe：bare 2.53 > turn 1.62 > triple 1.57。
- **lockbox 分年 RankIC**：2019–2022 仍为正（+0.011~+0.035，量级持续衰减），**2023 归零、
  2024 转负（−0.04~−0.07）**——与 REV 族 2023–2024 拥挤衰减同模式，与 PV_ANTI_TRIPLE
  （2024 +0.103）形成鲜明对照。整个反转族的近三年衰减是跨族现象。
- **成本三档**（协议条款 6，三因子换手 59–63%/日均）：多空排序在 0.05/0.10/0.15% 单边
  全档位不变（bare > turn ≥ triple）→ 门槛通过。但注意：test 段扣费后净多空
  bare +24.1% vs turn +7.1%（0.10% 档）——**多空+扣费视角更支持 bare**；
  主推按冻结纪律仍为 valid RankIR 选出的 turn，此分歧如实记录（"IC 选择 vs 组合现实"
  的教学对照，不回改）。

## 过拟合防治执行清单

- 事前协议（分段/预算 80/噪声门槛 0.19/lockbox/成本门槛）先于 round_01 落盘；
- 台账：56/80 次，新 valid 从 0 计；主推 naive t = 0.292×√487 ≈ 6.4（重叠折半 ≈ 4.6）
  ≫ 噪声锚 √(2·ln 56) ≈ 2.84；
- 参数平台：diff 窗 3/4/5 → 0.261/0.276/0.238（平台），amp 窗 3–10 死平台；
- 复跑一致性：round_03 双跑 metrics md5 逐位一致；PV_ANTI_BARE 跨轮复现（g2_04 = g4_10）；
- 简形式纪律：组合（+0.013）、amp 乘法器（−0.012）均因低于噪声不采纳；
- 留存冻结（runs/final/retention.md）先于 final_report.py，test/lockbox 未参与任何选择；
- 工程踩坑：orthogonality.py 初版缺少 `if __name__ == "__main__"` 保护，Windows spawn
  进程池下 worker 反复重导入顶层代码导致卡死 ~16 分钟——正是本项目笔记记录过的坑
  （wiki/code/alpha-mining-demo-notes 关键决策 3），加 main() 保护后 28s 完成。

## 局限性

1. valid 2017–2018 曾作为前三族 test 被观察 3 次 + 跨方向排序 1 次（间接加热）；
2. 859 只池 point-in-time 性未核查（幸存者偏差方向与过拟合一致）；涨跌停/停牌可交易性
   未建模——反转语义下想买的低开票可能恰好卖不出，实际可实现收益低于本报告；
3. IC/RankIR 口径未扣费；扣费后 turn 主推地位受 bare 挑战（见终局确认）；
4. lockbox 显示 2023–2024 衰减转负：留存因子的"当前期望"应按衰减打折，任何实盘化
   需先做近三年滚动 RankIC 监控；
5. 单市场（A 股）、单池（沪深300）、单一 label 视界（T+3）。
